# ScamShield

ScamShield helps everyday internet users understand warning signs in suspicious messages without sending message content off-device.

## Run & Operate

- `pnpm --filter @workspace/api-server run dev` — run the API server (port 5000)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- Required env: `DATABASE_URL` — Postgres connection string

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- API: Express 5
- DB: PostgreSQL + Drizzle ORM
- Validation: Zod (`zod/v4`), `drizzle-zod`
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)

## Architecture decisions

- Message analysis is browser-only; never send or persist the message text.
- Risk scores are transparent, unvalidated heuristics, not probabilities or definitive scam verdicts.
- Keep the application free of automatic link opening or URL-fetching behavior.

## Product

Users can paste or select a fictional sample message, see explainable warning signs and a capped risk score, and read practical verification advice. Students and everyday internet users are the primary audience.
