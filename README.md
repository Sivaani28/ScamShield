# ScamShield 🔴

**Spot the red flags before you click.**

ScamShield is a web application that helps users identify potential scam messages by detecting suspicious wording, links, urgency, and other common warning signs.

## 🌐 Live Demo

[Open ScamShield](https://scam-shield-message-analyzer--sivaani289.replit.app/)

## ✨ Features

- Analyzes pasted messages for common scam indicators.
- Generates a risk score from 0 to 100.
- Explains detected warning signs.
- Provides practical safety recommendations.
- Includes sample messages for testing.
- Uses a responsive, dark cybersecurity-inspired interface.

## 🛠️ Tech Stack

- React
- TypeScript
- Tailwind CSS 
- Rule-based message analysis

## 🔍 How It Works

1. Paste a message into the analyzer.
2. Click the Analyze button.
3. ScamShield checks the message against configured warning-sign rules.
4. Review the risk score, detected indicators, and safety tips.

## 🔒 Privacy

The intended design processes messages locally in the browser without storing their contents. Verify this against the actual implementation before relying on this claim.

## ⚠️ Limitations

ScamShield is an educational awareness tool, not a definitive scam detector. Its score is based on configured rules, not a scientifically validated probability. A low score does not guarantee that a message is safe.
